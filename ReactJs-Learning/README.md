# ReactJs-Learning — my React study notes & practice code

By **Adarsh** — this folder is my hands-on React course. Every concept is
a small file I wrote while learning it.

## How to use

1. Follow `00_ROADMAP.md` in order.
2. JSX files here are reference code — drop them into a Vite app to run:
   `npm create vite@latest my-app -- --template react`
3. Key ideas are in the `NN_*.jsx/.js` lesson files; hooks each get a file.
4. Finish with `PRACTICE_CHALLENGES.md`, then read the project folders
   next door (react-source is the real React!).

## Files

- `00_ROADMAP.md` — my study order
- `01`–`28` — JSX basics → components → hooks → patterns → performance
- `CHEATSHEET.md` — quick reference
- `PRACTICE_CHALLENGES.md` — 25 build-it challenges
